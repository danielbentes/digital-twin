## Methodology

This profile was generated by the `digital-twin` skill via 6 passes over your own Claude Code session logs plus a structuring pass:

1. **Extract** — Walked `~/.claude/projects/*/*.jsonl` ({{N_SESSION_FILES}} files).
2. **Quantitative** — Counted prompts, vocab, slash commands, languages.
3. **Temporal** — Hour/day histograms, work bursts, recovery cycles, drift.
4. **Qualitative agents** — 6 parallel general-purpose agents each producing a 1500–2500 word deep read.
4.5. **Insights extraction** — Single Sonnet call structures the 6 free-form reports into card-shaped JSON (one file per section).
5. **Deep sources** — Memory inventory, plan inventory, assistant-turn pairs, PR comments.
6. **Synthesize** — Fills this template + the twin agent + the CLAUDE.md patch. If the insights JSON is present, cards above are populated from it; otherwise they fall back to rule-based content.

Total wall-clock: ~{{TOTAL_WALL_CLOCK_MIN}} minutes.

Re-run with `/digital-twin:update` to refresh against new logs.
